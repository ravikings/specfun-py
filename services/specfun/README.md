The README you are reading backs the `[project] readme` field in
pyproject.toml. Without it, setuptools publishes the package with no
long_description, and `twine check --strict` rejects the distribution
(nativegate 0.1.1 handles this automatically; see the repository root
README for the project).

This directory is the nativegate service for the netlib specfun
collection. The chain is:

    native/*.f   upstream Fortran (see ../../PROVENANCE.md)
                 -> bindings + CMake generated by `ngate generate specfun`
                 -> wheel built by `ngate build specfun`
                 -> values pinned by `ngate golden record specfun`

Regenerate at any time:

    ngate generate specfun
    ngate build specfun
    ngate golden verify specfun
